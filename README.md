# Aurum Management App

The Aurum Management App is a proprietary software tool developed by Aurum for the management of its fitness centers. It is built using the Flutter framework and is intended for internal use only.

## Features

The Aurum Management App includes the following features:

- Member management: add, edit, and remove member information
- Class scheduling: schedule fitness classes and manage attendance
- Equipment tracking: monitor equipment maintenance and inventory
- Billing and payments: process member payments and track revenue

## Getting Started

### Requirements

- Flutter 2.0 or later
- Dart 2.12 or later

### Installation

1. Clone the repository:

git clone git@github.com:aurum/management-app.git

2. Install dependencies:

flutter pub get

3. Launch the app:

flutter run
